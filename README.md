# technews-today

Projeto desenvolvido como atividade de HTML e CSS, com o objetivo de criar um portal de notícias sobre tecnologia.

##  Sobre o projeto

O **TechNews Today** é um portal de notícias voltado para o mundo da tecnologia. A página apresenta uma notícia em destaque, uma área de vídeo e um formulário de inscrição para newsletter.

O projeto foi desenvolvido utilizando apenas **HTML e CSS**, sem frameworks ou JavaScript.

##  Objetivos

O objetivo do projeto é desenvolver um portal de notícias sobre tecnologia, apresentando informações de forma organizada, moderna e acessível. A página reúne notícias, conteúdo em vídeo e uma área de inscrição em newsletter para proporcionar uma experiência completa ao usuário.

##  Tecnologias utilizadas

- HTML5
- CSS3
